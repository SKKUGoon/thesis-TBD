## 디자인 기준

사용자가 확정한 두 번째 대시보드를 유일한 UI로 사용한다. 초기 디자인 원본과 이전 UI는 로컬 Git 복구 참조에만 보존하고 실행 소스에서 삭제했다. 좌측 아이콘 메뉴·접이식 사이드바·반투명 카드·왼쪽 환자 및 약품 그래프·오른쪽 발주표를 실데이터에 연결했다. 목업의 임의 수치·약품 명단·주문·경매·AI 답변은 운영 화면으로 복사하지 않았다.

## 실제 연결

- 환자 카드: 현재 예측 입력 snapshot의 과거 28일 입원·외래 집계. 별도 API는 전체 집계까지 반환하며 식별값은 반환하지 않는다.
- 예측 카드: 실제 보유 품목, 이전 14일 예측 전체 점선, 이번 예측, 실제 사용/기록 출고량, 쉬운 표현의 오차·날짜별 표.
- 발주표: 실제 30품목의 14일 예측 합계. 표시만 소수 둘째 자리로 반올림하며 저장값과 계산에는 Decimal 정밀도를 유지한다.
- 주간 자료 버튼: 기존 멱등성·작업 추적·재시도 계약을 이용한다. 승인·접수·입고와 자료·처리 내역은 대시보드의 기능별 창에서 제공한다. 이전 5단계 탐색·예측 화면은 삭제했다.
- 업무 조회: 현재 자료의 예측·재고 등록 상태·처리 작업을 조회한다. 자유 질문 LLM은 미연결이며 생성형 분석으로 표시하지 않는다.
- 경보: 실제 미등록 정보와 실패 작업으로만 구성한다. 경매는 미연결이며 입찰·가격·마감 시각을 만들지 않는다.

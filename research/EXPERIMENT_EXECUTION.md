# 단일 약품 정보 그룹 예측 실험 실행 순서

- 작성일: 2026-10-07, Asia/Seoul.
- 기준: [연구계획서 v1.14](RESEARCH_PROPOSAL.md).
- 상태: 2026-10-07 단일 제품 행정 코드 그룹의 ARIMA 탐색 실행 완료. 무기록 의미·역사적 메타데이터·가용시각 확인 전의 제한적 실행이며 정식 주 실험 완료는 아니다. [방법론](methods/ARIMA.md), [실행 결과](../runs/cheonan/arima_native_missing_20261007_01/report.md).
- 최신 확장 실행: 뉴론텍캡슐100밀리그램·Forcep jar의 XGBoost/CatBoost/LightGBM Expanding 평가와 논문 기반 공급 효용성 가정 계산 완료. [보고서](../runs/cheonan/boosting_two_items_20261007_01/report.md), [방법론](methods/BOOSTING.md). 물품 무기록은 보완하지 않고 관측 출고일에 조건부 평가했다.
- 이전 약품 실행: 필수 달력·과거 환자 구성·KCD·정부 대응기간을 포함한 XGBoost/Ridge 후향적 평가와 검증 완료. [수정 결과](../runs/cheonan/xgboost_standard_features_20261007_01/report.md). VARX/TimesFM 및 실제 물류 개선은 미실행. 병원 상품 전환·진료·구매정책은 입력에서 제외한다.
- 완료 목표: 소비 패턴을 사용하지 않고 고정한 약품 그룹 한 개에 대해 총소모량과 품목별 예측 결과를 비교·저장·보고한다.

## 2. 단계별 실행

### 0. 입력과 실험 기록 준비

- 원자료, 기존 무손실 Parquet, 외부 ATC 원본/변환 manifest의 경로·행/열·해시를 확인한다. 기존 변환을 불필요하게 다시 수행하지 않는다.
- v1.8의 수량 계약, 제품 정보 전용 그룹, 2020–2024 기간, H=14, 월별 재적합·월요일 평가를 초기 실행 명세로 기록한다.
- 과거 메타데이터 가용성을 확인한 실험인지, 현재 분류를 사용하는 명시적 후향적 실험인지 구분한다. 최근 ATC 자료를 과거에 알려진 정보라고 표시하지 않는다.
- 자료 가용시각·추출 완전성·상품 전환 공지의 보유 여부를 확인한다. 미확인 항목은 실제 확인과 가정 시나리오를 구분한다.
- 실제 구현 시에만 src/·tests/·configs/와 잠금된 의존성 명세를 만든다. 원자료·무손실 사본은 덮어쓰지 않는다.

**산출물:** 입력 manifest, 분석 계약, 가용성 확인표, 실행 상태 기록.

### 1. 병원–ATC 연결표 생성

- 병원 약품 마스터의 품목코드·품목명·표준코드·단위·규격과 외부 ATC의 제품 정보를 필요한 열 중심으로 읽는다. 환자 전체 자료는 아직 읽지 않는다.
- 공식 코드 연결 근거를 우선 사용한다. 제품명·업체·성분·함량·제형 등으로 만든 후보는 검토 상태와 모호성을 남긴다.
- 외부 item_seq 중복 때문에 병원 코드 한 개가 여러 참조 행에 연결되는지 검사한다. 같은 문자열 길이의 코드를 동일 체계라고 가정하지 않는다.
- 성분·함량·제형·투여 경로·기본 단위와 과거 유효시점 근거를 확인한다. 같은 ATC를 임상적 대체 가능성 확인으로 취급하지 않는다.

**산출물:** `drug_metadata_mapping.parquet`, 연결·미연결·모호 품목 집계, 근거·검토 기록.

**진행 조건:** 그룹 구성에 사용할 상품 정보의 대응이 확인되어야 한다. 불확실한 값은 소비 패턴이나 LLM 추정으로 확정하지 않는다.

### 2. 약품 정보 그룹 한 개 고정

- 소비 자료를 그룹 함수에 전달하지 않는다. ATC·성분 조합·함량·제형·경로·기본 단위만으로 그룹 키를 만든다.
- ATC 3·4단계 후보를 세분하여 수량 비교가 가능한 소규모 그룹을 찾는다. 제조사·상품코드가 다르면 별도 품목으로 유지한다.
- 초기 학습경계까지 코드 존재가 확인된 품목 중 연결·단위·관측 범위 계약을 통과한 2–20개 구성원을 가진 그룹을 검토한다. 데이터 존재·추출 완전성은 품질 조건이며 소비 빈도·수요 규모·상관을 선정에 사용하지 않는다.
- 적격 그룹이 여러 개이면 v1.8의 정규화 그룹 키 사전식 순서로 첫 그룹을 선정한다. 선정·제외 사유를 기록하고 품목 순서와 그룹 해시를 고정한다.
- 후속 집계에서 품질 미충족이 발견되면 이유를 기록해 P1로 돌아간다. 높은 예측 성능이나 소비 유사성을 이유로 다른 그룹을 선택하지 않는다.

**산출물:** `frozen_single_group.parquet`, 그룹 명세·선정 사유·품목 순서·버전·해시.

**진행 조건:** 소비와 독립적인 구성 명단, 비교 가능한 단위가 확보되어야 한다. 적격 그룹 부재는 미선정으로 보고한다.

### 3. 선택 그룹의 일별 목표값 생성

- 사용기록은 날짜·약품코드 등 필요한 열을 파일별/배치별로 읽고 선택된 그룹 품목의 집계만 저장한다.
- 사용기록 1행을 기본 단위 1개로 세며 반복 행을 삭제하지 않는다. 참조표 연결 전후 원본 행수·품목별 수량이 보존되는지 대조한다.
- 품목별 `y(i,d)`와 비교 가능한 단위의 그룹 총량 `g(d)`를 생성한다. 취소·반납·정정은 근거가 확보된 규칙으로만 처리한다.
- 무거래 0, 미관측, 취급 범위와 사건일/가용시각을 분리한다. 그룹 구성원 중 하나라도 미관측이면 해당 그룹 총량도 미관측이다.
- 그룹 명단을 수정하지 않고 날짜·코드·단위·행수·그룹 합계·관측 상태를 검사한다.

**산출물:** `daily_item_consumption.parquet`, `daily_group_consumption.parquet`, `observation_masks.parquet`, 데이터 품질·수량 보존 검사.

### 4. 원점·특징·라벨 명세 생성

- 2020–2022 초기 학습, 2023년 1–6월 개발, 2023년 7–12월 순차 점검, 2024년 최종 평가로 날짜 역할을 분리한다.
- 월요일 원점 t마다 컷오프와 목표일 `t+h−1`, h=1…14를 명시한다. 1/7/14일 범위와 누적 합계의 이름을 구분한다.
- 입력은 원점에서 고정한다. 약품/그룹 지연 k_y=7/14/28/56, k=1 기준, TimesFM 문맥 28/56/112 후보를 명세한다. 후보가 요구하는 최대 이력 기준으로 공통 평가 원점을 만든다.
- XGBoost의 h별 학습 라벨 종료·가용시각을 검사한다. 전체 벡터 평가에는 14일 라벨이 모두 관측된 원점을 사용한다.
- MASE의 그룹·품목별 분모는 초기 학습구간의 m=7 계절 단순예측 MAE로 고정한다. 분모 0과 미관측 품목을 따로 표시한다.
- 과거 7/28일 상품 배분 기준선의 원점별 분모·가용성을 정의한다. 분모 0이면 배분 미정의로 기록한다.
- 환자 특징·정부 정책·공식 전환 공지는 보조 입력군이다. 각각 가용시각이 확인된 경우에만 추가하고 미확인 보조 입력 때문에 주 소모 이력 실험을 임의 보완하지 않는다.

**산출물:** `feature_spec.json`, 원점/라벨 테이블, 모형별 입력 참조, 초기 MASE 분모, 입력 가용성 감사표.

### 5. 합성자료로 불변성과 전환 검사

1. 소비량·상관·상품 구성비를 바꾸어도 제품 정보가 같으면 그룹 명단과 해시가 같아야 한다.
2. 미래 사용 행·정책·전환 공지를 바꾸어도 과거 원점 입력·고정된 모형의 과거 예측은 같아야 한다.
3. 총량 고정 A→B→A와 총량도 바뀌는 A→B→A 합성 경로를 나누어 실행한다. 실제 병원 전환을 확인한 것으로 표현하지 않는다.
4. 전환 일정이 미리 알려진 경우와 미공지인 경우를 별도로 만든다. 미래 실제 배분을 쓰는 예측이 아닌지 확인한다.
5. h별 라벨·14일 출력·품목 순서·총량 합계·과거 비율 배분을 검사한다.
6. 14일 계절 기준선도 원점 이후 실제값을 쓰지 않아야 한다. 가용성이 t−1까지인 완전 관측 예시는 마지막 7일을 반복하고, 둘째 주에 첫째 주 실제값을 참조하지 않는다. 관측 지연이 있으면 컷오프 전에 가용한 동일 요일 자료의 사용 규칙을 따로 명세한다.

**산출물:** `synthetic_switch_checks.json`, 누출·정렬 검사 결과, 실패 원인.

**진행 조건:** 과거 입력/예측 불변성 또는 수량 보존 검사가 실패하면 실제 튜닝으로 진행하지 않는다.

### 6. 기준선과 모델의 작은 경로 확인

실제 그룹에 대해서는 2023년 개발 원점 중 소수만 사용하고 성적을 근거로 그룹을 교체하지 않는다. 기존 합성 OLS 계산 성공을 실제 모델 호환 성공으로 간주하지 않는다.

| 실행 순서 | 확인할 조건 |
|---:|---|
| 6-1 | 계절 단순예측: 원점·14일 날짜·지연·실제값 정렬·완료 라벨 |
| 6-2 | 그룹 총량 ARIMA/SARIMA: 적합·상태 갱신·월별 모수 고정·출력 정렬 |
| 6-3 | 그룹 VAR: K품목 행렬, p=1/7, rank·표본 비율·정상성/변환·안정성·합계 |
| 6-4 | 총량 XGBoost: h별 직접 출력, 원점 고정 특징, 시간순 early stopping |
| 6-5 | TimesFM 총량/다변량: 고정 버전·가중치·사용 조건·Apple Silicon 장치·출력 형상·채널 간 정보 이용 |

실행 시간·최대 메모리·지원 문맥·오류·모형 크기를 기록하고 그 결과로 개발 튜닝의 후보 수·시간/메모리 상한을 정한다. 다른 모델 결과로 실패를 숨기지 않는다. 개별 모델 미지원은 기록한 뒤 실행 가능한 조건을 명시해 비교하고, 자료·누출 계약 실패는 실험 전체의 진행 중단 사유로 구분한다.

**산출물:** 모델별 호환·자원 표, 작은 경로 예측, 모델 manifest, 실패 기록.

### 7. 2023년 1–6월 튜닝·설정 동결

- 모든 후보를 같은 그룹·공통 개발 원점·같은 컷오프에서 비교한다. Expanding·월별 재적합·월요일 평가 규칙을 따른다.
- 순서상 기본 소모 이력 조건을 먼저 비교하고, 품목 구성/교차 약품 정보와 환자·정부 정책 조건은 별도 실험명으로 비교한다. 입력 정보가 다른 성능 차이를 순수 모델 구조 효과로 해석하지 않는다.
- ARIMA 차수·계절성, VAR p/변환, XGBoost 지연·구조·나무 수, TimesFM 문맥·지원 조건, 7/28일 배분 기준선을 개발자료로 선택한다.
- 그룹 총량의 h=1…14 동일가중 개발 MAE로 선정한다. 최소 20개 완료 공통 개발 벡터를 요구하며 동점은 복잡도·개발 처리시간 순이다.
- XGBoost early stopping은 개발에서만 사용하고 선정한 나무 수로 이후 월별 재적합한다. 환자 k_p와 소모 k_y는 독립 설정한다.
- 후보 목록·시행 수·자원 상한·음수 후처리·비교 원점·평가 분모·통계 설정·실패 처리·모형별 입력 열을 최종 설정에 기록한다.

**산출물:** `tuning_trials.parquet`, 선정 근거, 동결 설정·해시, 모델/입력 명세.

### 8. 2023년 7–12월 순차 점검

- 동결 설정으로 월별 재적합과 월요일 예측을 순서대로 재생한다.
- 자료 컷오프·완료 라벨·새 관측 반영·품목 순서·총량/배분 결과·파일 저장을 확인한다.
- 개발에서 정한 규칙대로 성과와 실패를 저장한다. 이 구간의 실패가 수정 필요성을 드러내면 변경 버전·사유를 기록하고 영향받는 검사를 다시 수행한 후 설정을 재동결한다.

**산출물:** 순차 점검 예측·지표·가용성 감사·변경 이력·최종 실행 설정.

### 9. 2024년 최종 순차 예측·평가

각 월요일 원점에서 다음 순서를 반복한다.

1. 그 원점까지 가용한 자료만 구성한다.
2. 월 첫 원점이면 고정된 규칙으로 재적합한다. 그 외에는 모수/가중치를 유지하고 최신 입력·상태만 갱신한다.
3. 동일한 14일 목표에 대해 그룹 총량, 가능한 품목별 예측, 과거 비율 배분을 생성한다.
4. 실제 적합 시각과 역사적 학습 컷오프를 구분해 저장한다. 원본 예측·후처리 결과·실패/미지원·입력 해시를 기록한다.
5. 라벨이 관측 완료된 뒤 평가한다. 연말에 전체 목표가 완료되지 않는 원점은 공통 종료 규칙으로 제외한다.

최종 MAE·편향·고정 분모 MASE·1/7/14일 누적 소모량 오차·기준선 대비 대응 차이·품목별 오차·배분 오차를 계산한다. 미래 실제 배분으로 총량 예측을 분해하지 않는다. 2024년을 본 뒤 그룹·후처리·평가 원점·모델을 다시 고르지 않는다.

## TimesFM 벡터 예측의 추가 실행 순서

[벡터 계획](methods/TIMESFM_VECTOR_PLAN.md)에 따라 2020–2022년 고빈도 약품 20개·물품 약 10개를 선정하고 두 코호트의 목표·관측 마스크를 각각 고정하고 공식 버전/API·독립 문맥·장치·합성 3채널·미래 불변성을 먼저 검사한다. 물품의 미관측 과거 수량을 처리할 수 있음을 확인한 뒤 2023년 문맥 개발, 2024년 공동/독립 예측, 같은 주문 정책 효율 평가, 확대 실행 디렉터리의 새 통합 보고서 작성 순으로 진행한다. 기존 2품목 결과는 예비 실험으로 보존한다. 계획 작성만 완료했으며 TimesFM 추론은 미실행이다.


## 2026-10-08 첫 TimesFM 실행 완료

약품 20개·물품 10개를 과거 기준으로 선정하고 TimesFM 3.0의 공식 `model.decode` 관측 마스크로 별도 공동 예측 및 품목별 독립 예측을 실행했다. 고수준 자동 보간은 사용하지 않았다. Apple Silicon PyTorch MPS에서 실행했고 환자 문맥은 28일로 고정했다. 2023년 상반기 24개 공통 원점에서 28/56/112일 목표 문맥을 비교하여 약품 112일·물품 56일을 선정했다. 마지막 28일 밖의 환자 값은 마스크로 가려 목표 문맥과 독립적으로 제한했다. 전체 환자 지연 후보 비교와 확대 부스팅 비교는 이번 첫 실행에 포함하지 않았다.

2024년 51개 원점·14일 예측의 품목별 동일 가중 MASE는 약품 공동 0.8353/독립 0.8597, 물품 공동 1.5429/독립 1.5413이었다. 공동 예측의 이점은 약품 약 2.84%, 물품 약 −0.10%로 나타났다. 미관측 목표는 평가에서 제외하고 비율을 품목별로 보고했다.

같은 최초 재고·납기 1일·서비스 목표 95%·가정 비용에서 2023년 하반기 안전재고를 선정하고 2024년 동결 정책을 비교했다. 양쪽 95%를 충족한 품목은 약품 14/20, 물품 2/10개였고, 그중 예측 활용으로 비용이 감소한 품목은 약품 13개·물품 1개였다. 양쪽 서비스 충족 품목의 동일 가중 평균 비용 감소율은 약품 32.87%, 물품 0.31%다. 물품 구간 초기화·미확인 단위 환산·실제 비용/재고/납기 부재로 실제 운영 개선을 주장하지 않는다.

[이번 통합 보고서](../runs/cheonan/timesfm_vector_20261008_01/report.md)에서 이름·변수·모델·절차·그림·지표·정책 효용성·가정·한계를 함께 제시한다. 새 모델/예측/원장/실패/원본 실행 코드 snapshot과 자료·체크포인트 해시는 같은 실행 디렉터리에 보존했다. 집중 검사 6개와 예측 정렬·미래 입력 불변성·원장 재고 보존 검사를 통과했다. 2024년 후향적 평가 및 기초모델 사전학습 중복 위험은 유지한다.

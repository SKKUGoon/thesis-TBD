# 천안의료원 물류 연구계획서 독립 검토 및 반영 기록

- 검토일: 2026-10-06 (Asia/Seoul)
- 대상: [연구계획서 v1.0 보존본](RESEARCH_PROPOSAL_v1.0.md). 현재 [v1.5 연구계획서](../RESEARCH_PROPOSAL.md)의 대상 변경은 이번 검토 범위에 포함되지 않는다.
- 검토 방식: 초안 작성자와 별도의 새 Agent가 문서와 저장소 지침을 읽고 비판 검토. 문서 수정·모델 실행은 하지 않음.
- 1차 판정: **조건부 타당. 문서상 치명적 과학 오류는 발견하지 않았으나 실행 규칙 보완 필요.**
- 검토 범위: 실현 가능성, 시간 누출, 물품 분류·변수 설명, 정책 수지·초기조건·비용, 재현·저장·개인정보.
- 한계: Agent 검토는 병원의 자료 의미 확인, 통계·물류 전문가 심사, 실제 모델 실행 또는 기관 승인을 대체하지 않는다.

## 1. 독립 검토 의견과 수정

| 번호 | 우선순위 | 검토자가 지적한 Gap | 문서 반영 |
|---|---|---|---|
| G1 | 높음 | 오전 발주의 당일 수요 포함과 도착일 경계가 불명확 | §7·9·10: 당일 미관측 수요 포함, t…t+H−1, 보호기간 t…t+R+L−1, t+L 시작 도착 명시 |
| G2 | 높음 | 안전재고 산식·표본·선택 규칙 부족. 시험기간에서 공급 목표 충족 후보를 고를 위험 | §10·11: 과거 총수요 오차의 경험적 버퍼 후보, higher 계산법, 최소 표본, 개발구간 순차 정책 선정, 동점·미선정 규칙. 2024년은 선정 정책 평가만 수행 |

G6의 모델 저장 경로와 G3의 제거 실험 재튜닝 문구 일부는 검토 진행 중 작성자가 먼저 보완했다. 검토 결과를 반영하여 원점별 모형 상태·설명 대상·안전재고 재보정 계약까지 확장했다.

## 2. 검토 후 추가 설계 변경

- 보정 구간을 2023년 7–12월로 확대하고 모델 튜닝을 1–6월로 분리하여 보호기간별 과거 오차 표본을 확보한다.
- 보정 원점은 하루 간격으로 생성하되 실제 비중첩 구간 수를 별도로 세고 표본 부족 정책을 보류한다.
- 안전재고 분위수 수준을 실제 공급 충족률 또는 보장된 coverage와 동일시하지 않는다.
- 시험기간 공급 목표 미달 품목을 제거한 결과만으로 전체 효율화를 주장하지 않는다.
- 문서의 기본 수치는 연구 설계값이며 실증·임상 권고가 아니라는 점을 명시한다.

## 3. 남은 진행 조건

1. 업무상 출고·입고 의미, 단위·중복·미관측 날짜, 자료 사용 가능 시점을 담당자에게 확인해야 한다.
2. 분류표와 적격 코호트·주기 기준·서비스 목표·납기·포장·비용·자원·통계 설정은 최종 평가 전에 동결해야 한다.
3. ARIMA·TimesFM의 설치·호환·처리시간과 누출 불변성 검사는 아직 실행하지 않았다.
4. 실제 재고·비용 절감 주장에는 실재고·주문·납기·기존 정책 확인이 별도로 필요하다.
5. 2024년 EDA를 이미 확인했다는 한계와 2026년 공개 foundation model의 후향적 사용을 보고해야 한다.

## 4. 수정본 재검토

v0.2 재검토 판정도 **조건부 타당**이다. 기존 높은 우선순위 2개와 중간 우선순위 5개가 계획 수준에서 해소됐다고 확인했다. 새로운 중간 우선순위 1개는 안전재고의 시간 계약 모순이었다.

- 추가 지적 G8: 전체 보정기간 잔차로 산출한 고정 버퍼를 같은 기간의 앞선 날짜에 적용하면 당시 가용 정보만의 순차 경로가 아니다.
- 검토자 제안: 개발용 후보 재생과 실제 당시 가용정보 기반 평가를 명확히 구분하고 최종 첫 컷오프의 잔차만 사용한다.
- 작성자 반영: 더 엄격한 방식으로 수정했다. 보정 중에도 각 원점의 확정된 과거 잔차만 사용한다. 공통 보정 시작일·최소 평가일을 명시하고, 최종 버퍼·초기재고·정책 선정에는 첫 평가 컷오프까지 사용 가능한 자료만 허용한다. 미확정된 2023년 말 기록을 날짜만 보고 포함하지 않는다.
- v0.3 확인: 동일 Agent가 마지막 시간 계약 모순의 해소를 확인했다. 확인 범위에서 새로운 높은 우선순위 문제나 치명적 오류는 발견하지 않았다.

## 5. 최종 판정

**조건부 타당.** 계획 수준의 8개 지적을 반영하고 독립 Agent의 최종 확인을 받았다. 전달본은 연구계획서 v1.0이다. 자료 의미·사용 가능 시점 확인, 미확정 규칙 동결, 모델 호환·누출 검사 통과가 다음 단계 조건이다. 현재 모델 성능이나 실제 물류 개선을 검증한 상태는 아니다.

## 6. v1.1 대상 및 수량 계약 변경

2026-10-06 사용자 제공 기준에 따라 사용기록 1행 = 약품 기본 단위 1개 소모를 채택하고 주 분석을 약품 소모량으로 변경했다. 수량 열 부재를 목표값 부재로 해석한 기존 문구를 수정했다. 사용기록 반복 행 보존, 약품코드·단위 연결, 무기록 날짜의 별도 확인, 같은 사용기록에서 생성한 환자 변수의 목표일 누출 금지를 반영했다. 이 수정은 사용자 지시에 따른 것이며 새로운 독립 Agent 검토를 수행한 결과가 아니다. 위 조건부 타당 판정은 v1.0에 관한 이력으로 보존한다.

## 7. v1.2 코로나 선행연구 및 예측 갱신 설계

2026-10-06 코로나 자료의 개입 시계열 처리 및 코로나를 포함한 누적 학습 예측 사례를 확인하고 §2.1·7.4·7.5에 반영했다. 약품 소비 영향 분석과 예측 검증을 구분했으며 월별 재학습은 문헌이 입증한 최적 주기가 아닌 본 연구의 설계임을 명시했다. 코로나 이전 기준자료 부족, 사건 시점의 가용성, 같은 원점에서의 민감도 비교를 추가했다. 이번 수정에 대한 새 독립 Agent 검토·모델 실행은 수행하지 않았다.

## 8. v1.3 정부 정책 Boolean

사용자 제안에 따라 병원체명 대신 국가 감염병 거리두기 대응 정책 기간을 Boolean으로 정의했다. 정부의 넓은 거리두기 정책 체계와 감염병 발발·종식 자체를 구분하고 공식 도입·해제 근거를 연결했다. 사건일과 발표 가용시각을 분리하여 사후 종료일 누출을 금지했다. 2023–2024년 정책 변수가 False이므로 시행 중 예측·다음 감염병 이전 가능성은 별도 검증이 필요함을 기록했다. 이번 변경에 대한 새 독립 Agent 검토나 모델 실행은 수행하지 않았다.

## 9. v1.4 다일 이력 입력 설계

약품 소모량의 t−1…t−k 이력을 사용하고 ARIMA 차수, XGBoost 지연 특징 수, TimesFM 문맥 길이를 구분했다. 미래 목표일별 실제 관측값을 입력에 섞지 않는 원점 고정과 이력 길이 비교의 공통 표본 조건을 추가했다. 수치 후보는 연구 설계이며 최적값으로 검증된 결과가 아니다. 이번 수정은 특징 생성·모델 실행 또는 새 독립 Agent 검토 결과가 아니다.

## 10. v1.5 입력군별 지연 길이

사용자 지적에 따라 약품 소모 이력 k_y와 환자 활동 이력 k_p를 독립적으로 선택하도록 수정했다. 약품 7일·환자 28일은 검증할 가정으로 유지하며, 공통 원점·개발기간 조합 선택·튜닝 예산·다른 입력군 고정 비교·모델별 길이 호환 조건을 추가했다. 선택된 길이를 인과적 효과 지속기간으로 표현하지 않는다. 새로운 독립 Agent 검토나 특징 생성·모델 실행은 수행하지 않았다.

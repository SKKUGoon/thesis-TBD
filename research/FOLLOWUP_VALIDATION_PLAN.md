# TimesFM 병원 확장과 예측 비교 및 추가 데이터 계획

작성일: 2026-10-11. 기존 v1.14의 천안의료원 20개 약품·10개 물품 및 2024년 결과는 그대로 보존한다. 아래는 후속 실험 계획이며 새 병원 예측이나 동일 20개 약품 비교모형 실행 결과가 아니다.

서송에는 의료소모품 **입고 기록**이 있다. 현재 보관 자료에서는 서송과 이푸른 모두 실제 구매 **발주 기록**을 확인하지 못했다. 따라서 다른 병원 확장은 서송을 우선 대상으로 준비하되, 입고량 예측과 소모량 예측을 구분한다. 교수님이 요청한 비교군은 천안의료원의 같은 20개 약품에 단순 예측과 다른 모델을 적용하여 19.82%의 상대적 의미를 보여주는 실험으로 구성한다. 추가 데이터 후보는 부족한 업무 정보를 구체적으로 설명할 수 있는 품목에서 선정한다.

## 1 다른 병원 자료와 예측 목표

### 1.1 현재 자료 점검

원자료 전체를 읽지 않았다. 서송 환자 파일은 대표 파일의 시트·열 이름만, 이푸른 약 1.06GB CSV는 헤더만 확인했다. 상대적으로 작은 서송 입고 파일에서는 2023·2024·2025 시트의 품목·단위·날짜·EDI 공란만 집계했다. 아래 날짜 범위는 원문 날짜 문자열의 최소·최대이며 정식 날짜 유효성 검사는 후속 가공 단계에서 수행한다.

| 병원 | 보관 자료에서 확인한 항목 | 발주 기록 판단 | 후속 용도 |
|---|---|---|---|
| 서송 | 의료소모품 파일의 품목 및 규격·단위·수량·단가·합계·EDI코드·부가세·입고일자. 환자 파일에는 처방 보험코드·병원 처방코드·이름 등이 있음 | 입고일자는 있으나 발주일·발주번호·발주수량을 구분한 항목은 없음 | 입고량 외부 사례와 처방 기록 기반 예측 후보 |
| 이푸른 | 현재 raw 폴더에 환자·청구 CSV 한 개. 청구코드·한글명칭·q_per_c·date·환자 구성 등이 있음 | 별도 구매·입고 파일이나 구매 발주를 식별하는 열을 확인하지 못함 | 이번 우선 병원에서 제외 |

서송 `DatOdrCod`의 명칭에 order가 들어 있어도 구매 발주로 해석하지 않는다. 환자 파일 안의 처방·진료 코드와 공급자 구매 발주는 별개다. 이푸른의 단가·금액도 청구 자료 안의 열이므로 구매 비용이라고 판단하지 않는다. 이 판단은 현재 보관된 파일 범위에 한정한다.

| 서송 입고 시트 | 비어 있지 않은 행 | 서로 다른 원문 품목명 | 날짜 원문 범위 | EDI 공란 |
|---|---:|---:|---|---:|
| 2023 | 2,250 | 602 | 2023.03.02–2023.12.20 | 1,742행, 77.42% |
| 2024 | 2,214 | 476 | 2024.01.03–2024.12.31 | 1,638행, 73.98% |
| 2025 | 1,866 | 338 | 2025.01.15–2025.10.29 | 1,375행, 73.69% |

서로 다른 원문 이름 수는 제품 수와 동일하지 않다. 단위도 box·개·100개/통 등이 섞여 있고 공란이 있다. 수량×단가와 합계의 차이가 포장 환산인지 세금·기록 방식인지 확인하기 전 자동 환산하지 않는다. `2023(구)`와 `샘플데이터` 시트를 실제 입고 시트에 합치지 않는다.

### 1.2 서송 실험의 두 목표

1. **입고량 예측:** 의료소모품 약 10개를 별도 벡터로 예측한다. 구매 발주량이나 환자 실제 소모량으로 표시하지 않는다. 품목 연결·동일 수량 단위·거래 추출 완전성을 먼저 확인한다.
2. **약품 사용 기록 예측:** 약품으로 확인된 품목 약 20개를 별도 벡터로 예측한다. 진료행위 코드를 약품에 포함하지 않는다. 반복 행을 모두 보존하고, 약품 사용일 및 한 행의 수량 의미가 확인되기 전에는 처방 기록 수로만 정의한다. 천안의 수량 계약을 다른 병원에 자동 적용하지 않는다.

두 목표가 모두 준비되지 않으면 준비된 목표만 실행하고 부족한 항목을 보고한다. 사용자 지정의 '실제 주문 기록이 있는 병원' 조건은 현재 확인 자료로 충족되지 않는다. 실제 발주량을 목표로 하려면 발주일·발주품목·수량·단위·취소 및 입고 연결 자료가 추가로 필요하다.

### 1.3 가공과 시간 분할

1. 원자료를 보존하며 새 무손실 Parquet와 자료·코드 해시 manifest를 생성한다. 기존 서송 집계에는 과거 중복 제거 및 날짜 정의에 관한 재검증 필요성이 있으므로 기존 `data_prescription.parquet`를 새 실험의 정답으로 바로 사용하지 않는다.
2. 서송 입원 파일의 `ManComDte`·`ManDisDte`가 입퇴원일인지 처방 사건일인지 확인한다. 입원일에 해당 입원기간의 모든 처방을 몰아서 세거나 미래 퇴원일로 과거 재원 상태를 복원하지 않는다. 성별·연령 집계 과정에서도 환자 식별값을 출력하거나 저장 산출물에 포함하지 않는다.
3. **입고 목표의 잠정 분할:** 2023년 대상 선정·초기 이력, 2024년 상반기 맥락 길이 개발, 2024년 하반기 설정 동결, 2025년 관측 종료일까지 평가. 2025년 전체가 있다고 가정하지 않는다. 실제 최종 유효일과 14일 라벨 완결성을 확인한 뒤 원점 목록을 고정한다.
4. 품목은 초기 기간의 입고 기록 날짜 빈도와 제품·단위 적격성으로 선정한다. 이를 임상적 클러스터링이라고 부르지 않는다. 평가 성적으로 구성원을 바꾸지 않는다.
5. 거래 없는 날을 0으로 정의하려면 품목 취급기간과 완전한 입고 원장이 필요하다. 확인되지 않으면 결측 마스크를 유지한다. 양의 입고일만 평가하는 결과는 입고 발생 여부를 예측한 성과와 다르므로 평가 범위를 명시한다.

### 1.4 TimesFM 적용 계약

[기존 사용 방식](methods/TIMESFM_VECTOR_PLAN.md)의 공식 코드 commit·체크포인트·native masked decode·9개 분위수 중 중앙값·비음수 점 예측을 재사용한다. 체크포인트는 기존 기록의 revision과 파일 해시로 명시적으로 고정한다. 약품·물품은 별도 다변량 Y 벡터로 입력하며 서로 다른 단위를 총량으로 합치지 않는다.

주별 원점에서 전날까지의 목표·환자 자료와 당시 알려진 달력만 입력하고 앞으로 14일을 예측한다. 목표 맥락은 28/56/112일을 개발 기간에서만 비교하고 환자 이력은 첫 복제 실험에서 28일로 고정한다. 고정 가중치에 최신 입력을 넣는 방식이며 Expanding 재학습이라고 표현하지 않는다.

환자 입력은 전체·남녀·입원/외래·10세 연령·공식 KCD 대분류 및 공란 범주를 같은 정의로 재집계한다. 기존 39열 환자 파일이 천안 69열과 호환된다고 가정하지 않는다. 당시 입원 활동 및 부상병 등 필수 항목을 구성할 수 없으면 동일 입력 외부 검증은 미완료로 표시하고 축소 입력 탐색을 별도 조건으로 구분한다.

2025년까지의 역사 자료에 2026년 공개 모델을 적용하는 후향적 병원 확장이다. 기초모델의 사전학습 종료일·병원 자료 중복은 별도로 확인해야 하므로 진정한 당시 실시간 운영 검증으로 표시하지 않는다.

입고량만으로 잠재 소모량·실재고·미충족 수요를 알아낼 수 없다. 소모 기록과 재고가 연결되지 않으면 천안의 수요 기반 주문 정책 시뮬레이션을 서송 입고 목표에 그대로 적용하지 않는다.

## 2 약품 20개 오차율과 비교군

### 2.1 교수님 질문의 의미

질문은 '19%라는 숫자만으로 좋은 예측이라고 판단할 수 있는가', '단순하게 예측해도 비슷하게 맞추는가', '이 정도 오차로 실제 주문에 도움이 되는가'라는 세 가지로 해석할 수 있다. 비교군은 우선 **동일 약품·동일 날짜의 예측 기준모형**이다. 다른 병원 검증은 별도로 일반화 가능성을 보여준다.

현재 19.8154%는 약품별 전체 평가 절대오차 합계를 관측 사용량 합계로 나눈 WAPE를 구한 뒤 20개 품목에 동일 가중치를 준 평균이다. 일별 오차율 평균인 MAPE나 '80.2%의 날짜를 맞혔다'는 정확도가 아니다. 품목마다 계산 단위·관측 범위가 다르므로 20개 약품의 수량을 그냥 합쳐 하나의 오차율로 만들지 않는다.

현재 MASE 평균 0.835도 2020–2022년의 주간 변동을 분모로 쓴 값이다. 2024년 단순 예측보다 16.5% 우수하다는 증거로 해석하지 않는다. 기존 뉴론텍 1개 부스팅 성적은 이번 20개 약품과 대상이 달라 평균 비교군이 될 수 없다.

### 2.2 비교 조건

| 비교군 | 예측 방법 | 역할 |
|---|---|---|
| 마지막 관측값 반복 | 원점 이전 마지막 확인 수량을 앞으로 14일 반복 | 가장 단순한 수준 유지 기준 |
| 지난주 요일 반복 | 원점 이전 마지막 완결 주의 같은 요일 수량을 2주 반복 | 요일 규칙만으로 얻는 성능 |
| XGBoost·LightGBM·CatBoost | 필수 X와 과거 목표 지연을 사용 | 이미 연구에 포함된 학습모형 비교 |
| TimesFM | 현재 동결된 약품 20채널 다변량 조건 | 평가할 주 모델 |

단순 예측을 기준모형으로 두는 근거는 Hyndman과 Athanasopoulos의 [Forecasting Principles and Practice 5.2](https://otexts.com/fpp3/simple-methods.html)이며 평가 원칙은 [5.8](https://otexts.com/fpp3/accuracy.html)을 따른다. 논문마다 다른 병원·기간·수량·오차 정의의 수치를 가져와 우열을 결론 내리지 않는다.

1. 천안의 기존 20개 약품과 2024년 51개 원점·14일 예측을 고정한다. 물품 10개는 별도 표로 평가한다. TimesFM 저장 예측을 재사용하고 2024년 결과로 설정을 재선택하지 않는다.
2. 14일 예측에서 8–14일째의 지난주 값은 원점 이후의 실제값이 되므로 사용하지 않는다. 두 번째 주에도 원점 이전 마지막 주를 반복한다. 원점별 사용한 실제 입력 날짜를 저장한다.
3. 부스팅은 Expanding 학습과 월별 재적합을 적용한다. 목표 지연 후보 7/28/56/112일과 환자 지연 후보 7/28/56일을 독립 선택하되, 2023년 개발 구간과 사전 동결한 탐색 예산만 사용한다. 학습 라벨 종료일도 원점보다 이전이어야 한다. 미래 환자 수는 넣지 않는다.
4. 약품 주 비교에는 군 내 약품의 과거 지연과 필수 X를 제공한다. 부스팅의 품목별 출력은 VAR과 같은 벡터 모형으로 부르지 않는다. 물품의 환자 입력 중심 기존 계약은 유지하고 자체 출고 이력 추가 실험은 별도 조건으로 보고한다.
5. 실제값이 확인된 평가행과 각 모델의 예측 가능 범위를 구분한다. 전체 TimesFM 결과와 공통 비교 가능 범위 결과를 함께 제시한다. 기준선 입력 결측을 0으로 바꾸지 않고 미지원 건수·관측률을 남긴다. 2020–2022년 MASE 분모를 공통 적용하며 분모 0·미정의는 그대로 보고한다.
6. 기존 중첩 14일 결과를 재현하고, 비중복 7일 평가 및 1–7일·8–14일 예측을 추가한다. 주간 총수량 오차는 모든 7일 실제값이 확인된 주에서 같은 원점의 일별 예측을 합산하여 계산한다. 불완전 주를 완전한 주간 총량처럼 취급하지 않는다.
7. 품목별 WAPE·MAE·편향·관측률과 20개 평균·중앙값·분포·개선/악화 품목 수를 보고한다. 상대 오차 감소율은 동일 범위의 기준선 오차 대비 감소로 계산한다. 반복된 일별 평가행을 독립 표본으로 취급하지 않고 비중복 주의 모델 간 오차 차이를 4주 블록으로 재표집하여 불확실성을 보조 보고한다.
8. 효용성에는 기존 공통 재고·납기·비용·서비스 조건을 유지한다. 예측 활용 대 예측 미활용 정책을 주 비교로 두고 모델별 정책 차이는 보조로 제시한다. 비용 감소와 공급 목표 충족을 함께 판단하며 실제 운영 비용 절감으로 표현하지 않는다.

최종 표는 '비교군 오차율 / TimesFM 오차율 / 상대 감소율 / 관측 범위 / 공급 충족률 / 가정 비용'으로 구성한다. 비교군 오차율은 실행 전 빈칸으로 두며 유리한 수치를 예시 결과처럼 채우지 않는다. 19.82%를 허용 가능한 수준으로 판정하는 보편적인 경계값은 설정하지 않는다.

## 3 천안의료원 추가 데이터 후보

### 3.1 요청의 해석

'데이터가 더 있으면 좋은 결과가 나올 품목'은 현재의 사용·환자 집계로 설명하지 못하는 정보가 무엇인지 밝히고, 추가 수집의 우선순위를 제시하라는 의미로 해석한다. 단순히 더 오래된 기록을 늘리는 것과 새로운 업무 변수를 확보하는 것은 별도 실험이다. 현재 자료에서 가능성이 있는 후보를 선정할 수 있지만 성능 개선은 추가 자료를 받아 검증하기 전 확정할 수 없다.

### 3.2 우선 후보

선정 근거는 저장된 **2023년 상반기 개발 예측**의 오차와 제품 용도에 따른 업무 가설이다. 기존 2024년 주 결과의 품목 구성은 바꾸지 않는다. 표의 WAPE는 반복 원점별 14일 평가행에서 계산된 개발기간 진단값이며 추가 변수의 효과를 측정한 값이 아니다.

| 후보 품목 | 개발기간 WAPE | 추가로 요청할 자료 | 검증할 가설 |
|---|---:|---|---|
| 포리부틴서방정300mg | 40.28% | 실제 투약 실행일·수량·투약 일수 및 취소·반납의 사건 기록 | 방문 단위 집계가 놓치는 실제 투약량과 기록일 차이를 구분하면 수량 목표와 예측이 개선되는지 확인 |
| 명인트라조돈캅셀25mg | 29.01% | 원점 당시 확인된 재원 환자 활동·투약 실행·진료과별 과거 활동 | 총 방문자 수보다 해당 진료 활동을 구분한 정보가 추가 예측력을 갖는지 확인 |
| Forcep jar | 32.53% | 출고·반납·멸균 완료·세트 회전 기록과 원점까지 완료된 관련 처치 수 | 출고가 환자 총량보다 실제 처치·재처리 업무에 연결되는지 확인 |
| Dressing set 뚜껑있는 것 | 52.76% | 드레싱 처치 기록·부서별 불출·반납·출고 사건시각 | 부서별 작업량과 묶음 출고의 차이가 오차를 설명하는지 확인 |
| Suture set | 56.92% | 봉합 관련 과거 처치 수·불출 및 반납 기록, 당시 공개된 처치 예약 | 전체 환자 구성보다 해당 처치 활동과 일정이 추가 예측력을 갖는지 확인 |

제품 이름만으로 해당 병원에서의 용도를 확정하지 않는다. 우선 자료 담당자에게 코드 연결과 업무 의미를 확인한다. 진료과·처치 기록은 관측된 임상 활동이며, 이번 입력에서 제외한 병원의 진료·구매 정책을 추정하는 변수가 아니다.

케이페리정50mg도 별도의 **기록 연속성 확인 후보**다. 2024년 현재 평가에서 관측이 344/714행인 점을 사후 품질 진단으로 남기되, 사용 중단·결품·상품 전환의 원인을 추정하거나 기존 평균에서 빼지 않는다. 완전한 사용 추출과 코드·단위 연결 자료를 우선 확인한다.

### 3.3 추가 자료의 검증 방식

1. 각 자료에 사건시각·자료 가용시각·품목 연결·수량 단위·정정 및 반납의 의미를 요청한다. 미래 실제 처치·퇴원·투약 일수를 과거 원점에 넣지 않는다. 미래 예약은 당시 예약 스냅샷이 남아 있는 경우에만 사용한다.
2. 같은 품목·같은 날짜·같은 모델에서 기존 입력과 추가 입력을 비교한다. 추가 자료가 있는 기간이 짧으면 두 조건 모두 그 공통 기간에서 평가한다. 효과가 없거나 악화된 결과도 저장한다.
3. 후보 및 추가 변수 선택은 개발 기간에서 동결한다. 현재 2024년 결과를 이미 본 후속 가설이므로 가능한 경우 아직 분석하지 않은 후속 기간에서 최종 검증한다. 자료가 없다면 후향적 탐색으로 명시한다.
4. 더 긴 이력의 효과는 새로운 관측 연도를 추가하는 실험과 입력 맥락을 늘리는 실험으로 나눈다. 기존 맥락 후보 안의 재비교와 더 긴 맥락 조건을 별도 보고한다. 오래된 기록이 반드시 도움이 된다고 가정하지 않는다.
5. 재고 실측·발주 및 입고 연결·실제 납기·결품·유효기간·구매 단가도 추가로 요청한다. 이는 주로 효용성 가정을 실제 운영 평가로 바꾸기 위한 자료이며 약품 소모량 예측 정확도가 자동 개선되는 변수는 아니다.

## 4 실행 순서와 결과 저장

1. **천안 기준선 비교:** 저장된 TimesFM 예측에 동일 원점의 단순 기준선을 연결하여 교수님 질문에 먼저 답한다.
2. **서송 자료 계약:** 입고 파일 무손실 변환·품목 및 단위 연결·날짜/가용시각·환자 집계 호환을 점검한다. 실제 발주 목표가 필요하면 발주 자료 확보를 선행한다.
3. **천안 동일 대상 부스팅:** 2023년 개발 설정을 동결한 뒤 20개 약품·10개 물품의 공통 평가를 실행한다.
4. **서송 TimesFM:** 작은 3–5품목에서 결측 마스크·정렬·미래 변경 불변성을 확인한 뒤 적격한 벡터 코호트로 확대한다.
5. **추가 데이터 검증:** 위 품목별 요청 자료를 확보하고 공통 기간의 입력 추가 실험 및 후속 기간 검증을 진행한다.

새 병원 자료는 `data/processed/seosong/analysis/<dataset_id>/`, 실행은 `runs/seosong/<run_id>/`에 저장한다. 천안 후속 실행은 기존 규칙대로 `runs/cheonan/<run_id>/`에 모은다. 기존 데이터·예측·보고서는 덮어쓰지 않는다. 이 계획 자체는 주 연구계획의 결과나 완료 상태를 바꾸지 않는다.

각 실행에는 설정·모델 및 체크포인트 해시·대상 선정·원점/입력 종료/라벨 종료·관측 마스크·실패·예측·지표·정책 원장을 보존한다. 실행 코드는 `src/methods/`의 해당 방법론에, 재현 계약은 `research/methods/`에 남긴다. 보고서는 실제 이름과 목표, 변수와 기간, 모델, 번호로 된 예측 절차, 그림, 수치와 해석, 해당 목표에서 평가 가능한 효용성 순으로 작성한다.

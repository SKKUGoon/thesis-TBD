### B. 자료 선정과 보존

1. 2020–2022년 약품 사용 행 수로 순위를 정했다. 반복 행을 삭제하지 않았고 사용자 기준인 1행=기본 단위 1개를 채택했다.
2. 같은 기간의 약품 원장에 단일 표준코드로 연결된 행정 코드만 같은 제품으로 묶었다. 같은 ATC라는 이유로 대체 약품을 합치지 않았다. 다중/불명 표준코드는 별도 후보로 남기고 주 20제품 선정에서 제외했다. 미래에 새로 발견한 코드의 과거 소모를 추가하지 않았다.
3. 물품은 양의 출고가 기록된 날짜 수로 순위를 정했다. 과거 명칭·행 구조·단위 검사를 통과한 후보에서 10개를 선택했다. 출고수량은 실제 환자 소비나 주문량으로 바꾸어 부르지 않았다.
4. 최초 물품 선정에 사용된 단위 개수 필드가 전체 기간을 참조한 것을 발견해, 2020–2022년의 단위 개수로 교정했다. 교정 전후 30개 채널의 이름·순서·모든 목표 값이 동일함을 확인했다. 두 자료셋과 감사 기록을 보존했다.
5. 실행 입력은 `timesfm_cohorts_20261008_01`, 교정 확인·재현용은 `timesfm_cohorts_20261008_02`다. 원자료와 일별 목표의 무기록은 NaN으로 유지했다. 선정 명단·후보 순위·제품 연결·목표·자료 해시를 각각 보존했다.

환자는 사용일 기준의 기록상 고유 환자로 집계했다. 전체·성별·입원/외래·10세 연령·주상병/부상병의 공식 KCD 대분류와 공란/분류불가를 포함한다. 병원 전체 내원 명부와 동일하다고 가정하지 않는다. 정보 가용시각은 미확인으로, 사건일 다음 날 가용 시나리오를 적용했다.

### C. 실제 입력 텐서와 결측 처리

실제 `adapter.predict_masked` 입력은 아래와 같다. `B`는 batch 수, `K`는 목표 품목 수, `C`는 목표 수량 문맥, `H=14`다. float32를 사용하며 모든 배열의 날짜와 품목 순서를 맞췄다.

| 배열 | 실제 형상 | 구현상 의미 |
|---|---|---|
| target | `(B,K,C)` | 원점 전날까지의 약품 사용/물품 출고 |
| patients | `(B,69,C)` | 목표와 같은 날짜 축으로 배열을 만들되 마지막 28일만 노출 |
| known | `(B,16,C+14)` | 과거·미래 날짜의 알려진 달력 입력 |
| target_mask | `(B,K,C)` | 비유한 목표 위치에서 True |
| past_only_mask | `(B,69,C)` | 비유한 환자 위치 및 마지막 28일보다 오래된 위치에서 True |
| 결과 | `(B,K,14,9)` | 목표 품목만 추출한 0.1–0.9 분위수 |

달력 16채널은 요일 one-hot 7개, 연간 sin/cos 2개, 공식 공휴일/일요일·명시 공휴일·공휴일 전날·다음날·주말·정부 거리두기 대응기간·원점 전날 대응기간 7개다. 공휴일·정부 대응 일정은 원점까지 공개된 발표만 반영한다. 미래 환자 실제값과 병원 구매/상품 전환 정책은 포함하지 않았다.

고수준 `forecaster.predict`/`predict_batch`는 결측을 보간하므로 **그 경로를 사용하지 않았다**. 공식 가중치를 로딩한 후 `forecaster.model.decode`를 호출하여 `target_mask`와 `past_only_mask`를 직접 전달했다. 마스크가 True인 위치에는 계산용 0 자리표시를 전달하지만 미관측 상태를 별도로 전달한다. 이것을 관측 수요 0 또는 원자료 0 대입으로 해석하지 않는다. 저장 자료의 NaN은 그대로다.

목표와 환자의 서로 다른 길이를 각각 다른 크기의 배열로 전달한 것이 아니다. **같은 C 길이의 환자 배열에서 오래된 위치를 마스크로 숨겨 정보 범위를 28일로 제한**했다. 목표 길이를 늘려도 추가 환자 관측을 노출하지 않는 방식이다.

`decode`는 공변량 채널도 반환하므로 결과의 앞 K개 목표 채널만 추출했다. 각 날짜의 분위수를 오름차순 정렬한 뒤 중앙 위치인 0.5 분위수를 `prediction_raw`로 저장하고, `prediction=max(0,prediction_raw)`를 정확도 평가·주문 정책에 사용했다. 분위수 q1–q9는 정렬한 값으로 보존했으며 음수 분위수 전체를 0으로 바꾸지는 않았다. 점예측을 단계에서 정수로 반올림하지 않았고 주문량 변환에서만 올림했다. 별도 z-normalization이나 원자료 평활화는 적용하지 않았으며 모델 내부의 정규화는 공식 구현을 사용했다.

### D. 실제 개발·평가 순서

1. **초기기간 기준을 고정했다.** 2020–2022년으로 대상, 품목 순서, MASE 분모와 재고 기준을 정했다.
2. **목표 문맥을 선택했다.** 2023-01-02–06-12 월요일 24개 원점에서 C=28/56/112를 평가했다. 원점별 14일 예측에서 관측 라벨의 품목별 MASE를 구하고 동일 가중 평균이 가장 낮은 C를 코호트별로 선택했다. 동점은 더 짧은 C를 선택하는 정렬이다. 개발 예측의 최종 대상일은 2023-06-25다.
3. **선택값을 동결했다.** 약품 112일, 물품 56일을 `contexts_frozen.json`에 저장했다. 환자 28일은 탐색 결과가 아니라 첫 실행의 고정 설정이다.
4. **정책 개발 예측을 생성했다.** 2023-07-03–12-04 월요일 23개 원점의 14일 예측을 사용했다. 설정상의 정책 개발 종료는 12-21이지만 마지막 예측 대상일은 12-17이며, 2일 예측 합계가 모두 있는 정책 의사결정 날짜는 최대 12-16이다. 존재하지 않는 12-18–21 예측을 채우지 않았다.
5. **2024년을 평가했다.** 2024-01-01–12-16 월요일 51개 원점에서 H=14를 예측했다. 최종 예측 대상일은 12-29다. 각 원점에 t−1까지의 최신 과거 입력을 사용했으며 모델 가중치는 유지했다.
6. **독립 비교를 보존했다.** 같은 원점·환자·달력·문맥·관측 라벨을 사용하여 각 품목을 단변량으로 예측했다. 네 품목씩 batch로 처리했지만 batch 축이 다른 독립 계열이다. 다변량의 품목 축과 구분한다.
7. **주문 평가를 수행했다.** 정책은 2024-01-01–12-26 중 공통 예측 가용·실제 기록이 있는 날짜에서 평가했다. 정확도 평가의 날짜 범위와 정책 평가 범위를 구분한다.

| 목표 문맥 C | 약품 개발 평균 MASE | 물품 개발 평균 MASE |
|---:|---:|---:|
| 28일 | 0.906081 | 1.356405 |
| 56일 | 0.889163 | **1.284649** |
| 112일 | **0.831937** | 1.300348 |

위 값은 `context_development_metrics.parquet`의 실제 개발 결과이며 2024년 성적으로 문맥을 다시 선택하지 않았다. TimesFM의 최근 문맥 갱신은 Expanding window의 모수 재학습이 아니다.

### E. 예측 지표·그림의 집계 규칙

- 원점×품목×대상일 단위로 실제값·예측·분위수·관측 여부를 저장했다. 51개 원점의 14일 예측이 겹치므로 품목마다 최대 714개 평가행이다. 고유 날짜 714일이라는 뜻이 아니다.
- 관측 실제값이 있는 행만 MAE·RMSE·편향·MASE·80% 구간 포함률을 계산했다. MASE 분모는 해당 품목의 2020–2022년 관측 가능한 7일 차이 절대평균이다. 분모가 0/미정의면 미정의로 남긴다.
- 10–90% 분위수의 경험적 포함률은 저장했다. 분위수별 pinball loss는 계획에 있었지만 첫 실행에서는 계산하지 않았다. 80% 구간을 95% 또는 교정된 공동 구간으로 부르지 않는다.
- 초기 지표 집계가 channel만 묶어 조건을 섞은 것을 수정해 `(channel,mode)`로 분리 계산했다. 저장 예측값을 바꾸지 않았다. 정정 전 코드와 정정 후 코드를 별도 snapshot으로 보존했다.
- 주 독자용 보고서는 다변량 조건만 사용한다. 전체 평균은 품목별 동일 가중 MASE와 WAPE이며 다른 단위의 원시 MAE를 합산하지 않는다. WAPE는 저장 결과의 사후 보고 지표이고 문맥 선정에는 사용하지 않았다.
- 그림은 같은 대상일의 최신 과거 원점 예측을 하나만 표시한다. 지표는 모든 평가 원점·horizon의 관측 라벨을 사용하므로 그림과 집계 방식이 다르다. 범례는 실제 사용/TimesFM이며 물품 실제 사용 표시는 기록 출고라는 의미를 본문에 설명한다.

### F. 예측을 주문 정책에 사용한 방식

품목별 2020–2022년의 **연속 관측된 오늘+다음 날 수량**으로 평균 μ와 표준편차 σ를 계산하고, 95분위수를 올림한 값을 최초 재고로 두었다. 두 정책은 같은 최초 재고·실제 기록 수량·납기·검토주기·비용을 사용했다.

| 설정/행동 | 실제 구현 |
|---|---|
| 고정 목표 정책 | `ceil(μ + bσ)` |
| TimesFM 목표 정책 | `ceil(최신 가용 원점의 오늘·다음 날 예측 합계 + bσ)` |
| 재고 위치 | 현재 보유+미도착 주문 |
| 주문 | `ceil(max(0,목표재고−재고위치))` |
| 하루 처리 | 예정 입고 수령 → 검토·발주 → 당일 수요 충족 → 종료 재고·부족비용 계산 |
| 검토/납기 | 매일 / 1일 |
| 비용 h/p/K | 보유 1/기본단위·일, 신규 부족 50/기본단위, 발주 5/회 |
| 안전재고 계수 b | 0/.5/1/1.5/2/3/4를 정책별로 개발기간에서 선정 |
| 서비스 목표 | 95%; 충족 후보의 최소비용, 없으면 최고충족률·최소비용 후보를 진단용 선정 |
| 품목 자료 부족 | 과거 연속 2일 창 30개 미만이면 실패 사유 저장 |
| 결품 | 신규 미충족 수량만 비용 부과. 이월 없는 lost-sales 가정 |
| 기록 공백 | 0 수요로 채우지 않음. 다음 연속 기록 구간에서 같은 최초 재고로 재시작 |

정책 설정은 2024년 결과로 바꾸지 않았다. 고정 목표 정책은 병원의 실제 현행 주문을 재현한 것이 아니다. 품목별 비용 감소율과 양쪽 서비스 충족 여부를 함께 보고한다. 기초 재고+입고=공급+종료 재고, 발주=도착+남은 미도착 주문을 구간별로 확인했다. 비용 구조·논문 근거·기호·해석은 [정책 방법론](ORDER_POLICY_COMPARISON.md)과 [통합 보고서](../../runs/cheonan/timesfm_vector_20261008_01/report.md)에 보존한다.

### H. 검증된 사항과 미완료 사항

합성 3채널의 형상·유한 출력, 오래된 환자 마스크 값 변경 불변성, 이웃 채널 변경의 다른 목표 반응, 미래 목표/환자 변경 시 과거 입력·예측 불변성을 확인했다. 실자료 3품목의 입력 검사 후 20/10채널로 실행했다. 집중 테스트 6개, 60개 품목×조건 지표 분리, 평가행 정렬·비음수 출력·정책 원장 보존과 교정 명단 동일성 검사를 통과했다. 모델 내부 모든 경로의 형식적 무누출 증명이나 임상적 인과관계 검정은 아니다.

미완료는 같은 30품목의 부스팅, 환자 문맥 전체 후보, 실제 납기/비용/재고 확인, 납기·비용 민감도, pinball loss, 통계적 유의성, 체크포인트 revision의 entrypoint 자동 고정이다. 2024년은 이미 EDA를 수행한 후향적 평가이고, 기초모델 사전학습 중복·자료 종료일은 미확인이다. 모든 종류의 data leakage가 배제되었다고 표현하지 않는다.

## 1. 연구 목적과 대상

한 품목의 수량만 출력하는 단변량 예측에서 여러 품목의 수량을 동시에 출력하는 벡터 예측으로 확장한다. TimesFM이 다른 품목의 과거 정보와 환자 구성을 활용했을 때 품목별 예측 성능과 예측 활용 주문 정책의 물류 효율이 개선되는지 평가한다. 공동 예측의 성능 향상을 사전에 전제하지 않는다.

| 대상 | 일별 목표 | 기본 단위 | 규모 |
|---|---|---|---|
| 사용기록이 많은 약품 | 제품별 사용 행 수 | 제품별 기본 단위 | 20개 제품, 20차원 벡터 |
| 기록 출고가 많은 물품 | 품목별 기록 출고수량 | 품목별 원자료 단위 | 약 10개 품목, 약 10차원 벡터 |

**선정 규칙:** 2020-01-01–2022-12-31 자료로만 순위를 정하고, 2023년 개발과 2024년 평가를 보기 전에 명단·순서를 동결한다. 약품은 반복 행을 포함한 사용 행 수가 많은 순으로 선정한다. 단위가 다른 약품의 빈도 순위는 기록량에 따른 실험 대상 선정이며 임상적 중요도 순위가 아니다. 같은 제품의 행정 코드 통합은 제품 정보로 확인된 연결만 허용하며, 코드 여러 개를 제품 여러 개로 세지 않는다. 미확인 연결은 별도 기록한다.

물품은 단위가 확인되고 행 중복·날짜별 충돌이 해소된 후보에서 선정한다. 단위가 서로 다른 출고수량을 직접 비교하지 않도록 **양의 출고가 기록된 날짜 수**를 주 순위로 사용한다. 같은 단위 내 누적 출고량은 보조 정보로 보고하고, 동점은 고정 품목 키 순으로 정한다. 제외 품목·사유·후보 수를 저장하며 10개 확보가 불가능하면 실제 확보 수와 원인을 보고한다. Forcep jar를 포함한 기존 한 품목 결과는 예비 실험이며 순위와 무관하게 강제 편입하지 않는다. 뉴론텍도 동일하게 처리한다.

이번 사용자 지정의 고빈도 코호트 선정은 **소비 패턴 클러스터링과 구분**한다. 과거 빈도를 대상 선정에 사용하되 상관·시계열 거리·예측 성능으로 묶거나 재선택하지 않는다. ATC·성분 등에 따른 임상/제품 그룹을 추가 정의할 때에는 기존 정보 전용 분류 계약을 유지한다. 두 코호트는 임상적 대체 그룹이 아니며 서로 다른 단위의 수량을 합산하지 않는다.

## 2. 벡터 목표와 입출력 정의

예측원점은 날짜 $t$의 시작이며 마지막 가용 사건일은 $t-1$로 둔다.

$$\mathbf{Y}^{\mathrm{drug}}_t=(y^{d}_{1,t},\ldots,y^{d}_{20,t})^\top\in\mathbb{R}^{20},\qquad \mathbf{Y}^{\mathrm{material}}_t=(y^{m}_{1,t},\ldots,y^{m}_{K_m,t})^\top\in\mathbb{R}^{K_m},\quad K_m\approx10$$

두 벡터를 각각 별도 호출로 예측한다. 약품은 `target[20,C] → forecast[20,14]`, 물품은 `target[K_m,C] → forecast[K_m,14]`다. 각 벡터 내부의 공동 예측과 품목별 독립 예측을 비교한다. 일반적인 $K$개 품목에서는 $\mathbf{Y}_t=(y_{1,t},\ldots,y_{K,t})^\top$다. 주 예측은 벡터 자체이며 그룹 합계는 수량 단위가 비교 가능한 약품 그룹에서만 보조 평가한다.

$$\widehat{\mathbf{Y}}_{t:t+H-1\mid t-1}=f_{\theta}\left(\mathbf{Y}_{t-C_y:t-1},\mathbf{X}^{\mathrm{past}}_{t-C_p:t-1},\mathbf{Z}^{\mathrm{known}}_{t-C_y:t+H-1\mid t-1}\right),\qquad H=14$$

이 식은 연구의 정보 범위를 정의한다. 서로 다른 문맥 길이 $C_y,C_p$를 실제 API가 그대로 받을 수 있다는 보장은 별도 호환 검사 전에는 하지 않는다. 원점 이전에 알려진 미래 달력만 $\mathbf Z$에 포함하고 미래 환자 실제값은 포함하지 않는다.

| 배열 | 논리적 형상 | 의미 |
|---|---|---|
| 목표 시계열 | `target[K, C_y]` | 같은 날짜 축·고정 품목 순서의 과거 수량 |
| 과거 환자 구성 | `past_covariates[69, C_p]` | 전체·성별·입원외래·10세 연령·KCD 진단별 과거 환자 수 |
| 과거·미래 달력 | `known_covariates[Q, C_y+H]` | 요일·주말·공휴일·연간 주기·정부 대응기간 |
| 점예측 | `forecast[K, H]` | 모든 품목의 향후 14일 수량 |
| 분위수 예측 | `quantiles[K, H, 9]` | 공식 예시의 0.1–0.9 분위수 |
| 관측 마스크 | `observed[K, C_y]` | 기록 관측과 미관측의 구분. 모델 수용 여부는 사전 검사 |

공식 예시는 목표와 과거 공변량에 같은 문맥 길이를 사용한다. 위 독립 길이 계약을 입력 어댑터에서 확인해야 하며, 미관측 마스크도 문서상 지원이 확인된 기능으로 가정하지 않는다.

## 4. TimesFM 모델과 공식 호환 근거

주 후보는 **TimesFM 3.0의 native multivariate 예측**이다. 공식 저장소는 목표 `(K,C)`에 과거 공변량과 미래에 알려진 공변량을 연결하여 `(K,H)`를 출력하는 예시와 Apple Silicon MLX 경로를 제공한다. 출처는 [공식 저장소](https://github.com/google-research/timesfm)와 [Google Research의 TimesFM-3 설명](https://research.google/blog/timesfm-3-a-zero-shot-foundation-model-for-multivariate-forecasting/)이며 2026-10-07에 확인했다.

| 구분 | 이 계획의 정의 |
|---|---|
| 공동 벡터 예측 | 한 다변량 입력에서 다른 채널 정보도 이용해 K개 목표 출력 |
| 독립 batch | K개의 독립 단변량 예측을 일괄 실행. 공동 예측이라고 부르지 않음 |
| VAR와의 관계 | 여러 목표·교차 정보를 쓴다는 공통점이 있지만 선형 VAR 방정식을 적합하는 모델은 아님 |
| 가중치 | 공식 체크포인트를 고정한 zero-shot 조건을 주안으로 사용 |
| 재학습 | 초기 실험에서는 병원 자료로 가중치를 재학습하지 않음 |
| 실행 기록 | 저장소 commit·배포 버전·체크포인트 revision·해시·라이선스·장치 고정 |

TimesFM 3.0 가중치는 공식 저장소에 별도의 비상업·비운영 사용 조건이 명시되어 있다. 본 계획은 로컬 연구 평가이며 상용 배포 실험을 포함하지 않는다. 다른 버전·가중치로 조용히 교체하지 않는다.

## 5. 자료 완전성과 실행 가능성 검사

새로 선정할 약품 20개와 물품 약 10개의 날짜별 관측 여부·연속 관측 길이·공통 원점을 다시 계산한다. 기존 뉴론텍·Forcep jar 2품목 자료의 공동 관측 진단을 확대 코호트의 진단으로 재사용하지 않는다. 품목 수가 늘수록 완전 공동 관측 구간이 짧아질 수 있으므로, 결측을 보완하지 않고 공식 입력 계약을 먼저 검증한다. 약품과 물품의 실행 가능성은 각각 판정하며 물품 실패를 이유로 약품 결과까지 성공/실패로 묶지 않는다.

| 점검 | 통과 조건 | 미통과 시 처리 |
|---|---|---|
| 과거 결측 처리 | 공식 구현의 마스크/NaN 계약을 확인하고 관측값과 미관측을 구분한 합성 검사 통과 | 해당 코호트 공동 실험 미실행으로 기록. 평균·0·보간·행 삭제로 맞추지 않음 |
| 독립 문맥 길이 | 약품 문맥과 환자 문맥의 다른 길이를 실제 API/어댑터에서 검증 | 독립 길이 조건은 미지원으로 명시. 같은 문맥 조건은 별도 이름으로 평가 |
| 장치·가중치 | 현재 장비에서 합성 3채널 입력·14일 출력이 유한하고 자원 한도 내 | 실패·시간·메모리 기록. 다른 모델 결과로 대체하지 않음 |
| 채널 순서 | 입력 품목 순서와 출력·정답·마스크 순서 일치 | 실행 중단 후 어댑터 수정 |
| 교차 채널 정보 이용 | 합성자료에서 이웃 채널의 과거값 변경 시 해당 의존 목표의 반응 검사 | 벡터 형상만으로 공동 정보 이용을 입증하지 않음 |
| 과거 입력 불변성 | 미래 사용·환자 행을 변경해도 이전 원점 입력·출력 불변 | 누출 원인 수정 전 실자료 실행 금지 |

누락 날짜를 삭제하여 인접 기록을 연속 일자로 가장하지 않는다. 결측 지원이 불충분하면 해당 벡터를 미지원으로 기록하고, 성공한 품목만 사후 골라 주 코호트로 바꾸지 않는다. 분할 또는 하위 집합 실험이 필요하면 평가 결과를 보기 전에 분할 규칙과 별도 조건명을 동결한다.

## 6. 문맥·학습·예측 일정

| 항목 | 계획 |
|---|---|
| 목표 문맥 후보 | `C_y=28,56,112`일; patch/padding 처리는 공식 구현 계약 확인 |
| 환자 문맥 후보 | `C_p=7,28,56`일을 독립 검토; 다른 길이 미지원이면 그 조건을 미지원으로 보고 |
| 동일 문맥 보조 조건 | `C_p=C_y`; 정보 범위를 별도로 표시하고 독립 길이 실험을 대체하지 않음 |
| 예측 범위 | 14일 일별 벡터, 앞 1/7/14일 성능 구분 |
| 원점 | 매주 월요일, 과거 t−1까지 입력 |
| 초기 기준자료 | 2020–2022년, 품목 순서·범주·척도·관측 계약 설정 |
| 문맥 선택 | 2023년 1–6월 원점에서만 선택 |
| 절차 검증·주문 설정 | 2023년 하반기; 정책 설정은 기존 비교와 같은 12월21일 컷오프 |
| 예측 평가 | 2024년, 공통 평가 원점 유지. 이미 열람한 후향적 평가 |
| 주문 평가 | 기존 정책 비교와 같은 2024-01-01–12-26 |

기존 부스팅은 Expanding 학습·월별 모수 재적합이었다. TimesFM zero-shot은 **과거 자료가 누적되더라도 고정 가중치에 선택한 최근 문맥을 갱신하는 추론**이다. 이를 Expanding 재학습이라고 부르지 않는다. 원점이 진행되며 사용할 수 있는 기록은 늘지만 입력은 C일 문맥이다. 추가 LoRA/미세조정은 별도 연구 조건이며 이번 계획의 실행과 섞지 않는다.

환자 문맥이 동일 길이로만 지원되는 경우에 lag 확장 공변량을 추가할 수 있으나 별도 실험으로 정의한다. 각 시점에서 환자 k_p개 lag를 만드는 방식은 전체 환자 정보 범위가 `C_y+k_p−1`일로 늘어나므로, 이를 환자 총 문맥 k_p일이라고 잘못 표시하지 않는다. 초기 계획에서는 호환성 확인 없이 이러한 대체 입력을 주 조건으로 실행하지 않는다.

## 7. 대조 조건과 벡터 예측 평가

| 조건 | 목표 | 목적 |
|---|---|---|
| TimesFM 공동 + 필수 X | 약품 20채널 / 물품 약 10채널, 별도 실행 | 주 모델 |
| TimesFM 독립 + 같은 필수 X | 각 품목별 단변량 | 공동 채널 정보의 추가 가치 |
| XGBoost·CatBoost·LightGBM | 동일 20개/약 10개 품목별 수량 | 확대 코호트에서 새로 실행할 비교 기준. 기존 2품목 결과로 대신하지 않음 |
| 주간 기록 기준모형 | 품목별 수량 | 예측 정확도 기준선. 예측 미활용 주문 정책과 구분 |

주 비교와 독립 비교에서 같은 목표·원점·관측 마스크·X·가용 범위를 유지한다. 공통 조건이 지원되지 않으면 정보 차이를 표시하고 순수 모델 구조 차이라고 해석하지 않는다. X 없는 조건은 추가적인 명시적 제거 실험일 뿐 필수 X가 포함된 주 모델을 대신하지 않는다.

품목별 MAE·RMSE·편향·MASE·원점 수·관측 비율을 저장한다. 서로 다른 단위의 원시 오차를 합쳐 하나의 점수로 만들지 않는다. 벡터 종합 지표는 초기기간에서만 고정한 품목별 척도로 정규화한 오차의 동일 가중 평균으로 별도 보고한다. 척도가 0 또는 계산 불가이면 미정의로 표시한다. 약품 합계는 동일 기본단위 그룹에서만 보조 평가한다.

0.1–0.9 분위수는 품목별 pinball loss와 10–90% 구간의 경험적 포함률로 점검한다. 그 구간을 95% 구간 또는 교정된 공동 예측구간으로 부르지 않는다. 품목별 분위수를 더하여 총수요의 분위수로 취급하지 않는다. raw 출력과 비음수 출력 처리 결과를 모두 보존한다.

## 8. 예측 활용 주문 정책의 효율 비교

TimesFM 출력의 각 품목 예측을 [기존 주문 정책 비교](ORDER_POLICY_COMPARISON.md)의 같은 재고 위치·주문 변환에 넣는다. 예측 미활용 정책의 정의와 세 부스팅 정책의 변환 규칙을 유지하되, 새 품목에서는 해당 품목의 과거 자료로 재설정하고 비교 예측을 새로 실행한다. TimesFM의 안전재고 후보는 같은 개발기간·서비스 목표·비용·후보 폭에서 선택한다.

| 항목 | 적용 |
|---|---|
| 주 조건 | 매일 검토·납기 1일·충족률 목표 95% |
| 비용 | 보유 1/단위·일, 새 부족 50/단위, 주문 5/회; 가정 비용 |
| 최초 재고 | 품목별 2020–2022년 관측된 보호기간 수량의 95분위수를 올림하여 설정. 같은 품목에서는 모든 정책 동일. 기존 30캡슐/40개를 다른 품목에 적용하지 않음 |
| 대조 정책 | 미래 수요 모델 없는 고정 목표재고 정책 |
| 활용 정책 | TimesFM 벡터 중 해당 품목 예측으로 목표재고 갱신 |
| 평가 지표 | 비용 감소율·충족률·평균/최대 재고·부족수량/일·주문횟수 |
| 서비스 판정 | 양쪽 95% 목표 충족 여부를 함께 표시 |
| 물품 범위 | 과거 입력 결측 해결 여부와 별개로 실제 기록 구간의 조건부 재고 평가 |
| 민감도 | 기존 납기 1/3일, 부족 비용 10/50/100 |

공급 효용성의 주안은 점예측과 사전 선정 안전재고의 조합이다. 분위수를 직접 목표재고로 쓰는 조건은 별도 실험이며 날짜별 분위수를 합산하지 않는다. 서로 다른 단위의 재고나 비용을 직접 합산하지 않는다. 품목별 비용 감소율과 서비스 목표 충족 여부를 제시하고, 코호트 요약은 동일 가중 비용 감소율·목표 충족 품목 비율로 보고한다. 가정 단가가 실제 비용과 같다는 주장을 하지 않는다. 실제 병원 비용·현행 업무 효과로 확정하지 않는다.

## 9. 누출 방지와 기초모델 해석

- 원점 이후 목표·환자 실제값은 입력하지 않는다. 공휴일·정부 대응기간은 원점 당시 발표된 정보만 사용한다.
- API에서 원점의 horizon 뒤를 past-only 공변량으로 보지 않는지 확인한다. 미래 환자 채널을 예측된 값과 실제값 사이에서 조용히 교체하지 않는다.
- 원자료 변경·대입·중복 제거 없이 날짜·품목 순서·가용 종료일·마스크를 검증한다.
- 문맥·스케일·그룹·후처리·안전재고·평가 분모는 원점 또는 개발 컷오프 이전 정보로만 정한다.
- 2026년 배포 기초모델을 2024년 자료에 적용하는 후향적 비교다. 사전학습 자료의 수집 종료일과 천안 자료 포함 여부가 확인되지 않았으므로 모델 사전학습 차원의 완전 무누출을 보장하지 않는다. 과제 입력의 시간 누출 검사와 사전학습 자료 중복 위험을 구분한다.
- 품목·환자 원본은 로컬에서만 처리하고 외부 서비스로 업로드하지 않는다.

## 10. 실행 순서와 저장 산출물

| 순서 | 작업 | 필수 산출물 |

| 2 | 2020–2022년 빈도 선정·제품 코드 연결·20/약 10 코호트 동결 | 후보 순위·선정/제외 사유·실제 이름·단위·자료 해시·품목 순서 |
| 2a | 코호트별 날짜·관측 마스크·단위 검사 | 두 목표 벡터 manifest·누락 현황·공통 원점 |
| 3 | 합성 3채널 입력·마스크·불변성·장비 검사 | 형상·유한값·시간·최대 메모리·실패 기록 |
| 4 | 실자료 3–5품목에서 시작하여 20/약 10채널 호환·자원 점검 | 코호트별 추론 가능/불가·시간·최대 메모리와 근거 |

| 6 | 2024년 공동/독립 벡터 예측 | `(origin,target_date,item)`별 실제값·예측·분위수·마스크 |
| 7 | 품목별 정확도와 주문 정책 비교 | 예측/효용성 지표·주문/입고/재고 원장 |
| 8 | 통합 보고서 갱신 | 이름→변수→모델→추론→그림→수치→정책 효율 순서 |

새 구현은 실행 시 `src/methods/timesfm/`, 설명은 이 문서, 새 데이터셋은 `data/processed/cheonan/analysis/<id>/`, 실행은 `runs/cheonan/<timesfm_vector_run_id>/`에 둔다. 첫 실행에 사용한 구현·모델 참조·실제 산출물을 보존하며 미실행 조건의 가상 결과를 만들지 않는다. 확대 실험의 사용자 진입점은 새 실행 디렉터리의 통합 보고서 하나로 둔다. [기존 2품목 통합 보고서](../../runs/cheonan/boosting_two_items_20261007_01/report.md)는 예비 실험으로 보존하며 새 30품목 결과를 기존 실행 결과로 표시하지 않는다.

## 11. 완료 기준

벡터 목표와 환자·달력 입력의 실제 호환, 미관측 처리의 타당성, 공통 원점의 joint/independent 비교, 품목별 정확도, 같은 조건의 주문 정책 효율, 재현 가능한 산출물과 한계를 모두 보고한다. 물품 결측을 처리할 수 없으면 해당 물품 벡터 실험은 미지원/자료 조건 미충족으로 보고하며 이미 실행한 부스팅 결과를 TimesFM 결과로 대신하지 않는다.


## 2026-10-08 TimesFM 첫 벡터 실험 실행 결과

약품 20개·물품 10개를 과거 기준으로 선정하고 TimesFM 3.0의 공식 `model.decode` 관측 마스크로 별도 공동 예측 및 품목별 독립 예측을 실행했다. 고수준 자동 보간은 사용하지 않았다. Apple Silicon PyTorch MPS에서 실행했고 환자 문맥은 28일로 고정했다. 2023년 상반기 24개 공통 원점에서 28/56/112일 목표 문맥을 비교하여 약품 112일·물품 56일을 선정했다. 마지막 28일 밖의 환자 값은 마스크로 가려 목표 문맥과 독립적으로 제한했다. 전체 환자 지연 후보 비교와 확대 부스팅 비교는 이번 첫 실행에 포함하지 않았다.

2024년 51개 원점·14일 예측의 품목별 동일 가중 MASE는 약품 공동 0.8353/독립 0.8597, 물품 공동 1.5429/독립 1.5413이었다. 공동 예측의 이점은 약품 약 2.84%, 물품 약 −0.10%로 나타났다. 미관측 목표는 평가에서 제외하고 비율을 품목별로 보고했다.

같은 최초 재고·납기 1일·서비스 목표 95%·가정 비용에서 2023년 하반기 안전재고를 선정하고 2024년 동결 정책을 비교했다. 양쪽 95%를 충족한 품목은 약품 14/20, 물품 2/10개였고, 그중 예측 활용으로 비용이 감소한 품목은 약품 13개·물품 1개였다. 양쪽 서비스 충족 품목의 동일 가중 평균 비용 감소율은 약품 32.87%, 물품 0.31%다. 물품 구간 초기화·미확인 단위 환산·실제 비용/재고/납기 부재로 실제 운영 개선을 주장하지 않는다.

[이번 통합 보고서](../../runs/cheonan/timesfm_vector_20261008_01/report.md)에서 이름·변수·모델·절차·그림·지표·정책 효용성·가정·한계를 함께 제시한다. 새 모델/예측/원장/실패/원본 실행 코드 snapshot과 자료·체크포인트 해시는 같은 실행 디렉터리에 보존했다. 집중 검사 6개와 예측 정렬·미래 입력 불변성·원장 재고 보존 검사를 통과했다. 2024년 후향적 평가 및 기초모델 사전학습 중복 위험은 유지한다.


## 재현 방법

실행 환경은 루트 의존성 명세와 uv.lock의 공식 저장소 commit 및 torch 버전으로 고정했다. 저장된 교정 선정 자료와 재현 설정을 사용한다. 원본 환자 행을 출력하지 않는다.

```sh
uv sync
uv run python -m src.methods.timesfm.run --config configs/timesfm_vector_reproduce.json
```

재현 설정은 새 실행 디렉터리를 사용하며 이미 존재하면 중단한다. 다른 실행 ID를 쓸 때에도 날짜·문맥·X·서비스 목표·비용을 바꾸지 않는다. 초기 실행 코드는 source_snapshot에, 지표 집계 정정 코드는 현재 run.py에 보존했다. 최초 물품 후보의 전체 기간 단위 개수 참조는 교정했고 명단·순서·모든 목표 값의 동일성을 확인했다. 공동/독립 지표 집계도 분리하여 저장했다. 원본 예측을 변경하지 않았다.


## 독자용 통합 보고서 작성 계약

현재 report.md는 비전공자에게 의미를 먼저 설명하고 기술 정의를 이어 제시한다. 본문 순서는 대상 요약→모델별 입력·기간·벡터 정의→모델→번호형 예측 절차→실제 사용/TimesFM 그림→다변량 모형 전체 평균→비용 의미·수식·공통 설정·개별 효용성 표/그림이다. 전체 품목과 개별 예측 지표는 부록으로 둔다. 하드웨어 내용은 본문에서 제외한다. 물품 그림의 실제 사용 범례는 기록 출고량이라는 의미를 바로 설명한다. 부스팅 2품목과 TimesFM 30품목의 성능을 같은 코호트 비교로 표현하지 않는다.

저장된 결과로 본문과 범례만 재작성할 때는 `uv run python -m src.methods.timesfm.reader_report`를 사용한다. 이전 본문·그림은 실행 디렉터리의 presentation_history에 보존한다. 예측·정책 원장은 변경하지 않는다.


## 2026-10-11 교수 코멘트 반영: 보고와 비용 집계

본문에 약품 20개·물품 10개의 전체 이름을 나열했다. 예측 기준선 비교는 주문 정책 비교와 분리했고, 4.42%포인트 감소와 반올림 전 지표의 상대 감소 18.3239%를 설명했다. 기존 정책 결과를 재사용하여 전체 30품목 macro 비용 감소 31.9220%, 양쪽 95% 충족 16품목 macro 감소 28.8035%를 제시했다. 품목별 예측 미활용 총비용을 100으로 정규화한 보유·부족·발주 구성의 동일 가중 평균을 추가했다. 서로 다른 단위의 원시 비용을 병원 화폐 총액으로 합산하지 않았다. 타세놀·Forcep jar·Cotton can(ss) 사례에 비용 구성과 부족량·발주 횟수를 제시했다.

95%는 기존 동결 시나리오다. Neve·Schmidt(2022; 온라인 2021)의 최소 충족률 90/95/99% 실험을 사후 문헌 근거로 연결했지만 해당 논문의 조사 주기 마지막 날 충족률과 본 연구 총수량 충족률은 집계 범위가 다르다. Carter·Hawa·Busby(2025; 온라인 2024)는 총수량 목표 99%이며 95%는 탐색 하한이다. 이를 95% 운영 기준의 직접 근거로 표시하지 않았다. 민감도는 미실행이다. 보고서만 수정했으며 예측·코호트·정책·가정 비용을 변경하지 않았다.

재현: `src.methods.timesfm.professor_revision.clarify_reader_report`는 동결 코호트와 정책 지표로 설명 및 표를 구성하며 `reader_report.write_reader_report`에서 호출한다. `revise_saved_reader_report(output, dataset)`은 그래프·예측을 변경하지 않고 기존 Markdown만 갱신한다. 보고서·PDF 이전 버전은 실행 폴더의 `presentation_history/pre_professor_revision_20261011/`에 보존한다. outbound는 PDF와 원본 PNG 복사본만 유지한다.


### 2026-10-11 평균 총비용 전후 값 추가

감소율 중심 표를 보완해 품목당 평가기간 누계의 동일 가중 평균 총비용을 제시했다. 전체 30개 23,583.3667→13,037.7667, 약품 20개 26,526.10→11,417.35, 물품 10개 17,697.90→16,278.60(가정 비용 단위). 보유·부족·발주 구성별 평균도 같은 분모로 계산했다. 앞서 추가한 정규화 비용지수 표는 전후 비용표로 대체했다. 품목별 감소율 평균과 평균 비용 비율을 구분하며 실제 원화나 일평균 비용으로 표시하지 않는다. 품목별 평가 구간이 다르며 목표 미달 품목도 전체 평균에 포함된다. 기존 예측·정책은 변경하지 않았다.


### 2026-10-11 비용 가중치의 독자 설명 보완

보유 1개·1일을 기준 1점, 당일 신규 부족 1개를 기준의 50배인 50점, 발주 1회를 기준의 5배인 5점으로 해석하는 비교용 가중치임을 본문과 표에 명시했다. 가상 하루 종료 재고 10개·신규 부족 2개·발주 1회는 10+100+5=115점이다. 전체 평균 비용도 점수로 표기했다. 실측 원화 및 실측 비용 비율로 해석하지 않으며 모형·정책·결과는 변경하지 않았다.

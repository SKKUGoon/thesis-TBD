# 이푸른 서송 TimesFM 약품 20개 예측 실행 방법

2026-10-11 사용자 요청으로 병원별 약품 20개 벡터의 예측 정확도를 평가하고 천안 통합 보고서의 부록 3과 4에 추가했다. 주문 정책은 실행하지 않았다. 병원별 기록 목표와 자료 범위가 달라 병원 사이 오차율을 직접적인 우열로 해석하지 않는다.

## 자료와 목표

| 항목 | 이푸른 | 서송 |
|---|---|---|
| 원본 | 환자·청구 CSV 3,510,225행, 필요한 열만 청크 읽기 | 2022–2024년 외래 연간 Excel, 922,010행 |
| 목표 | 원문 제품코드별 약품 처방·청구 행 수 | 원문 보험코드별 외래 약품 처방 행 수 |
| 사건 날짜 | 원본 date, 입원일로 대체하지 않음 | 외래 ManComDte. 과거 입원일에 연결된 입원·병동 자료 제외 |

약품이 기록되지 않은 날짜는 NaN으로 유지했다. 기록에 등장한 고유 환자의 전체·남녀·입원/외래/분류불가·10세 연령·공식 KCD 주/부상병 69열을 새로 구성했다. 이푸른의 보험 유형은 입원/외래 구분이 아니므로 해당 구분은 OTHER로 보존했다. 서송은 외래만 포함한다. 서송 진단의 주/부 구분은 원문 ByuMajYon Y 플래그에 따른 잠정 해석이다. 환자 기록이 없는 날은 모든 환자 특징을 결측으로 유지했다. 환자 식별값은 일별 고유 환자 수 계산 중에만 사용하고 산출물에 보존하지 않았다.

## 동결 설정과 재현

설정은 `configs/timesfm_external.json`, 원본 집계 코드는 `src/methods/timesfm/external_data.py`, 개발·예측·보고 코드는 `src/methods/timesfm/external_run.py`다. 공식 TimesFM commit e51928e27119cb17bebc005be2696b75e0a9e688 및 checkpoint google/timesfm-3.0-pytorch revision 43046b85ec22d584a13f8098c2ed39c889e129c2를 고정했다. 로컬 체크포인트 파일 해시를 실행 manifest에 기록했다. 비상업 라이선스이며 원자료를 모델 서비스로 전송하지 않았다.

1. 병원별 선정기간의 약품 기록 수 상위 20개를 고정한다. 품목을 임상적 그룹으로 합산하지 않는다.
2. 2023-01-02–06-12의 월요일 24개 원점에서 목표 이력 28/56/112일을 비교한다. 환자 이력은 독립된 28일이다.
3. 선정기간의 관측 가능한 7일 차이를 MASE 분모로 삼고 개발기간의 품목별 MASE 평균으로 이력 길이를 선택한다.
4. 2024-01-01–12-16의 월요일 51개 원점에서 H=14일을 예측한다. 병원마다 20×51×14=14,280개 예측행을 생성한다.
5. 공식 native masked decode, 9개 분위수 중 중앙값, 0 이상 점 예측을 사용한다. 원자료 보간·평균 대입·자동 0 대입 없이 고정 가중치로 추론한다.
6. 원점 이전 마지막 주를 두 예측 주에 반복한 기준선과 공통 관측 범위에서 비교한다. 평가 불가 약품은 그대로 남기고 평균에 들어간 품목 수를 표시한다.

```bash
uv sync
uv run python -m pytest -q tests/test_timesfm_inputs.py tests/test_timesfm_external.py
uv run python -m src.methods.timesfm.external_data --hospital epurun --dataset-id timesfm_external_20261011_01
uv run python -m src.methods.timesfm.external_data --hospital seosong --dataset-id timesfm_external_20261011_01
uv run python -m src.methods.timesfm.external_run --config configs/timesfm_external.json
```

가공 출력 디렉터리가 이미 있으면 원본 집계 명령은 실패한다. 새 데이터셋 ID로 실행하려면 설정도 그 ID로 변경한다. 실행 재개는 기존 동결 설정이 동일한 경우 저장된 개발·평가 예측을 재사용한다. 설정이 다르면 새 run 디렉터리를 사용해야 한다. 초기 이푸른 비교 단계의 평가 불가 품목 처리 실패는 `failure_history/`에 보존했고, 예측을 재선정하거나 대체하지 않고 보고 집계에서 명시적 미정의 처리를 추가했다.

자료는 `data/processed/<병원>/analysis/timesfm_external_20261011_01/`, 실행은 `runs/<병원>/timesfm_20_20261011_01/`에 저장했다. 병원별 manifest에 코드·자료·체크포인트 해시, 설정·선정·실패·Git 상태·자원·검증을 기록했다. 별도 보고서는 재현용이며 사용자 진입점은 천안 통합 보고서의 부록 3·4다. 공개 Git에 데이터와 실행 산출물을 추가하지 않는다.

미래 목표·환자 변경에 대한 입력·예측 불변성, 오래된 환자 마스크 불변성, 결측 보존, 공식 KCD D50 경계, 평가 불가 품목 보존, 예측행 수·정렬·순위 합계·비음수 검사를 완료했다. 기록일 다음 날 가용 가정과 실제 사건·수집·정정시각은 구분한다. 기초모델 사전학습 중복·수량 단위·기관 전체 내원자 포괄성·서송 입원 목표는 미확인이다. 2026년 모델의 역사 자료 적용은 후향적 평가다.

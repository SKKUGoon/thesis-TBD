# ATC 자료와 다변량 예측 가능성 점검

- 점검일: 2026-10-07, Asia/Seoul
> 이 문서는 v1.7 시점의 자료·계산 점검 기록입니다. 현재 v1.8은 소비 패턴을 그룹 구성에서 전면 제외하고 단일 정보 기반 그룹 예측에 한정합니다. 이전의 패턴 군집 확장 제안은 현재 실행 계획에 적용하지 않습니다.

- 범위: 외부 Excel 전체 값 변환, 병원 약품 마스터의 제한된 열·첫 4,096행, 공식 모델 문서, 합성 OLS 행렬 계산. 환자 원본 전체 읽기·병원 모델 학습·TimesFM 설치/추론은 하지 않았다.

## 결론

그룹별 VAR와 TimesFM 3.0 다변량을 비교할 수 있다. ARIMA는 선택한 품목별로 별도 적합하고, VAR는 여러 품목의 과거값을 함께 사용한다. 전 약품을 한 VAR로 적합할 때는 장비 메모리보다 모수 수 대비 학습 표본·정상성·관측 완전성이 우선 제약이다. ATC 그룹은 가능하지만 역사적 분류·코드 연결 근거가 아직 필요하다.

## ATC 파일의 내용과 변환

[원본 Excel](../data/external/atc(o).xlsx)의 Sheet1, A1:L7442를 읽었다. 헤더를 제외한 7,441행과 12열은 제품별 메타데이터다. 열은 item_seq, 제품명, atc_code, 업체명, 주성분, 함량, 공고대조약, 제네릭의약품, 생동성시험, 허가일, 취소취하일, 특허연계다. 모든 셀 값은 문자열이고 수식은 없다. 파일의 공식 배포기관·배포일·ATC 적용시점은 확정하지 않았다.

[원본값 Parquet](../data/processed/external/atc/original/atc.parquet)은 184,431바이트이며 Excel은 470,449바이트다. 원본 12열·순서·모든 행·문자열·공란을 보존하고 Zstandard로 압축했다. 평균 대입·중복 제거 없이 전체 값 왕복 일치와 Excel 해시 불변을 확인했다. [Manifest](../data/processed/external/atc/original/manifest.json)에 소스·결과 해시·정의·품질 수치를 기록했다.

ATC 코드에 영문 성분 설명이 붙은 값도 있다. 분석용 코드 추출은 원문을 별도 보존한 상태에서 수행한다. 5단계가 없는 334행은 상위 단계 코드이며 자동 불량 처리하지 않는다. [WHO 협력센터](https://atcddd.fhi.no/atc/structure_and_principles/)의 5단계 구조에 따르면 3단계·4단계 분류로 약품을 나누는 것이 가능하다. 이 파일에는 단계별 명칭 사전·DDD·병원코드 연결·재고 포장 환산 근거가 없다.

## 병원 약품 연결의 현재 한계

병원 약품 마스터에서 첫 4,096행의 품목코드·품목명·표준코드만 읽었다. 이 표본은 511개 병원 품목을 포함하며 품목코드 또는 표준코드와 외부 item_seq의 직접 일치가 모두 0건이다. 전체 연결률을 산출한 결과가 아니다. 표준코드의 정확한 체계를 확인하고 공식 변환표 또는 제품명·업체·성분·함량·제형의 근거 있는 연결을 수행해야 한다.

중복 참조 행을 그대로 결합해 사용 행을 늘리지 않는다. 연결표는 병원 품목·유효기간별 하나의 확정 분류 또는 명시적 모호 상태를 가지게 한다. 원본 중복과 반복 소모 행은 보존한다.

## 모델별 판단

| 조건 | 의미 | 현재 확인 |
|---|---|---|
| ARIMA/SARIMA | 품목별 시계열과 품목별 모수 | 모든 약품 실행이 필수는 아니며 선정 코호트에서 각각 적합. 병렬 처리와 joint 모델은 구분 |
| VAR | K개 약품과 서로의 과거값으로 K차원 출력 | 그룹별 행렬 계산 가능. 모수 수·rank·관측 범위·정상성·안정성 검사 필요 |
| TimesFM 독립 batch | 여러 독립 1차원 시계열을 배치 처리 | 여러 약품 처리 가능. 배치라는 이유만으로 약품 간 정보 이용이라고 해석하지 않음 |
| TimesFM 3.0 다변량 | (K, context) target에서 (K, H) 출력 | 현재 공식 다변량·공변량 예시 확인. 실제 설치·채널 간 정보 이용·메모리 검증 전 |

근거: [ARIMA 공식 명세](https://www.statsmodels.org/stable/generated/statsmodels.tsa.arima.model.ARIMA.html), [VAR 공식 문서](https://www.statsmodels.org/stable/vector_ar.html), [TimesFM 공식 저장소](https://github.com/google-research/timesfm).

VAR의 `Y_t = b + Σ_j A_j Y_(t−j) + e_t`에서 A_j는 K×K다. 초기 1,096일, 약품 목록의 769개, p=7을 예로 들면 방정식당 5,384개 설명변수에 가용 1,089일이므로 표준 OLS는 식별되지 않는다. 전체 코드 수가 최종 적격 약품 수라는 뜻은 아니다. 차원을 줄인 그룹 VAR를 우선 검토한다. 정규화 VAR는 별도 모델·튜닝으로 명시해야 한다.

현재 공식 TimesFM 3.0에는 Apple Silicon용 MLX 경로가 있다. 현재 장비는 M4 Pro·14 CPU 코어·24 GiB이며 이 경로는 실행 후보다. 가중치·버전·사용 조건을 고정하고 실제 작은 입력부터 확인해야 한다. 2.5의 XReg와 3.0 다변량 target을 같은 기능으로 설명하지 않는다.

## 장비의 합성 행렬 계산 확인

1,096일·7일 지연·14일 출력의 합성 자료에서 NumPy least-squares와 행렬 예측만 확인했다. 각 크기에 한 번 측정했으며 통계적 성능이나 실제 전체 튜닝 시간은 측정하지 않았다.

| 약품 수 K | 설계 행렬 | OLS 시간(초) |
|---:|---|---:|
| 10 | 1,089 × 71 | 0.008 |
| 25 | 1,089 × 176 | 0.021 |
| 50 | 1,089 × 351 | 0.049 |
| 100 | 1,089 × 701 | 0.144 |

전체 벤치마크 프로세스의 최대 RSS는 약69.4 MiB이며 모든 출력이 유한했다. K=50/100의 계산 성공은 계획의 보수적 표본 비율 조건을 통과했다는 뜻이 아니다. [원본 측정 기록](../data/processed/cheonan/diagnostics/multivariate_feasibility_20261007/synthetic_var_matrix_benchmark.json)을 보존했다.

## 그룹과 누출 통제

- 3단계 ATC를 시작점으로 하위 ATC·성분·제형으로 나누고 가용 표본에 맞춰 10–25품목 그룹 VAR를 검토한다. 작은 그룹·단일 품목·미연결은 따로 보고한다.
- 그룹 안에서도 약품별 수량·단위·목표를 유지한다. 합계 예측 뒤 실제 미래 비율로 배분하지 않는다.
- ATC 배정·병원 코드 연결의 당시 공개/유효시점을 확인한다. 최신 허가·취소·제네릭 상태로 과거 품목을 고르거나 제거하지 않는다. 과거 허가일만으로 당시 ATC 가용성을 입증하지 않는다.
- 학습기간에서 그룹을 고정한다. 패턴 군집이 필요하면 학습기간 특징·스케일러·군집만 적합하고 2024년 성적·상관을 쓰지 않는다.
- 같은 그룹·품목·공통 원점에서 개별 예측과 joint 예측을 E5로 비교한다. 원점 이전 자료만 입력하고 행렬 날짜·품목 순서·관측 마스크를 검증한다.
- 역사적 ATC 근거가 없는 최신 분류는 사후 설명·명시적 후향적 민감도에 한정한다. 그 결과를 당시 구현 가능한 운영 예측이라고 보고하지 않는다.

주 계획서 v1.7에 반영했다. v1.6 독립 검토는 이 신규 범위를 포함하지 않으며 새 범위의 독립 검토·병원 모델 실행은 미완료다.
